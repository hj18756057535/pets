# PetDesk

一个本地优先的 Windows 桌面宠物、会议提醒与数据脱敏工具。让小伙伴陪你工作，也让交给 AI 的资料先经过本地处理。当前为 **0.1 自用预览版**。

Windows x64 · 使用者无需 Node.js / Rust · 本地保存 · MIT 开源客户端

### 再试试本地数据脱敏

**本地脱敏快速体验：** 从桌宠右键或陪伴空间打开“本地数据脱敏”，添加虚构的客户名、项目名作为关键词，生成可恢复预览；将保留占位符的 AI 示例回复粘贴到“AI 结果还原”，选择对应映射即可恢复原词。关键词可保存成组复用，也可导入 Word/TXT 或选择 Excel/CSV 的指定列处理。操作前先预览，导出生成新文件。

## 普通用户：下载后双击使用

**不需要安装 Node.js、npm，也不需要输入命令。**

1. 在本仓库的 [Releases](https://github.com/hj18756057535/pets/releases) 页面下载 `PetDesk-…-windows-…-portable-….zip` 附件，不要下载 `Source code`。
2. 将整个 ZIP 解压到自己的文件夹，双击 **PetDesk.exe**。
3. 首次启动点击“导入宠物”，界面中有 [Codex Pets](https://codex-pets.net/) 下载入口和操作说明。
4. 想在桌面启动：右键 EXE 创建快捷方式，或双击随包提供的 `创建桌面快捷方式.vbs`。

保留便携包内的文件，不要直接在 ZIP 中运行。现在默认使用 Tauri + Windows WebView2，提供便携 ZIP 和 NSIS 安装包；用户无需安装 Node.js、Rust 或 npm。尚未提供自动更新。

## 开发者：从源码启动

只有开发、修改代码或自己打包时才需要 Node.js 22、Rust MSVC 工具链和 Microsoft C++ Build Tools。在项目目录执行：

```powershell
npm.cmd ci --cache .npm-cache
npm.cmd start
```

依赖安装完成后，也可双击源码目录的 `启动桌宠.cmd`，由无窗口引导程序启动；源码未改动时直接使用现有 EXE，首次或源码变化时才编译，启动后 PowerShell 立即退出；失败会弹出提示，日志在 `.data/launcher.log`。`npm.cmd start` 用于开发调试，会保留终端。安装版和便携版直接运行 EXE，不显示命令行窗口。源码仓库不附带第三方宠物素材，启动后通过界面导入。

## 使用

- 桌面宠物：拖动调整位置；单击挥手；双击打开陪伴空间；右键打开菜单，可直接逗猫、放球、跟随鼠标、结束互动或调整设置。
- 互动：在陪伴空间选择“逗猫棒”“放球取回”或“跟随鼠标”。放球时在当前屏幕点击选点，宠物会跑过去把球叼回原位。按 Esc、托盘“结束互动”或陪伴空间“结束互动”停止；单次最多 5 分钟。拖动宠物、换宠或隐藏桌宠也会结束互动。
- 系统内存：右键“查看系统内存”，或打开偏好设置，可查看总量、已用、可用和桌宠进程占用。“整理桌宠内存”仅整理 PetDesk 与其 WebView 子进程的工作集，不清理其他软件，数值会随使用回升，不保证加速。
- 默认尺寸为原来的 60%，偏好设置中可选择更小的 45% 迷你尺寸。
- 双击宠物打开陪伴空间；可自由拖动到桌面任意位置，靠近边缘也保持悬浮。宠物下方不再显示按钮，也可通过托盘菜单操作。
- 拖动以宠物画布位置计算边界，跨屏时跟随鼠标所在显示器；靠近屏幕顶部时提醒气泡向下显示，不再为上方气泡预留不可到达的区域。
- 陪伴空间：预览宠物、播放动作、导入其他宠物文件夹。
- 点击“换一位小伙伴 · 导入宠物”：可选择下载的 `.codex-pet.zip` / `.zip`、原有宠物文件夹，或粘贴 Codex Pets 分享链接。先读取并预览，再点击“使用这只宠物”。
- 分享链接支持 `https://codex-pets.net/share/宠物ID`、`https://codex-pets.net/pets/宠物ID` 和 `https://codex-pets.net/#/pets/宠物ID`。链接导入需要联网；成功后资源保存在本地，后续陪伴无需联网。
- 会议提醒：填写名称、开始时间和提前量；可以点击“体验一次提醒”在 10 秒后试用。
- 固定会议：选择每天、周一至周五或每周指定几天，按本机时区和首次会议时刻重复。首次日期须属于选择的星期；周一至周五不自动排除节假日。每次到期自动安排下一次，确认或稍后处理本次通知不会影响后续场次；通过待处理列表的“停止后续重复”取消系列。软件离线多次错过时只补一条旧通知，再安排未来场次。
- 在“会议提醒 → 已结束”点击“一键清除已结束记录”，保留待处理通知和未来会议。
- 时间输入：支持 `9`、`930`、`09:30`，可选下个整点、今天、明天、后天或最近的周几。也可输入“明天 09:30 晨会”“今天下午3点项目会”“下周一上午9点半项目会议”，点击“填入表单”后检查时间预览并保存。文字输入中的过期时间会报错，不会自动改期；默认仅提醒一次，也可切换会议模式设置重复。
- 提醒气泡保持独立字号，不随宠物缩小；长标题显示两行，点击箭头在列表查看全文。
- 宠物资源入口：[Codex Pets](https://codex-pets.net/)。下载 `.codex-pet.zip` 后直接导入，无需解压；已解压的资源请选择包含 `pet.json` 和 `spritesheet.webp` 的文件夹。导入窗口提供网站按钮和分步说明。
- 提醒到期：显示宠物气泡，可确认或推迟 5 分钟。Windows 通知可用时同步发送系统通知。
- 免打扰：暂停气泡与系统通知，到期提醒保存在列表；关闭免打扰后气泡恢复。
- 护眼提醒：默认开启，每使用 30 分钟弹出一条轮换的搞笑小纸条；在“偏好设置 → 让眼睛也摸会儿鱼”可关闭、设为 5～180 分钟，或体验文案。点击“去歇会儿”重新计时，“5 分钟后”按后续活动时间延后。会议优先，护眼提示不写入会议记录，也不累积多条。
- 护眼计时根据系统键鼠闲置时间估算使用时长，不监测视线。闲置 1 分钟暂停，2 分钟后重新计时；锁屏、休眠和重启后重新开始。免打扰时暂停计时与气泡；设置页也可处理护眼提醒。
- 关闭主窗口：软件仍在系统托盘运行。退出请使用托盘菜单或设置中的“退出软件”。
- 通知到达不会重新定位正在拖动的宠物；失焦、指针取消或拖动超时会清理拖动状态。Tauri 启动阶段及两个页面就绪状态记录到 `.data/app.log`。Teams 实际共享环境仍需现场复测。
- 找回窗口：双击系统托盘图标，或 `Ctrl + Shift + P`（若被其他软件占用，请使用托盘）。
- 暂时隐藏：只隐藏桌宠；提醒列表和系统通知仍可使用。

## 当前范围

### 本地数据脱敏（首版）

从桌宠右键、托盘菜单或陪伴空间左侧点击“本地数据脱敏”。工具按需启动为独立进程，关闭窗口后退出，不增加桌宠常驻窗口。也可双击新版便携包中的 `启动本地脱敏.vbs`，或单独执行 `PetDesk.exe --maskdesk`；源码开发使用 `npm.cmd run maskdesk`。

- 文本：添加关键词与替换值，生成预览后复制。按字面匹配、区分大小写、长词优先，替换结果不级联替换。
- 关键词库：按客户、项目或用途命名，保存新组、加载替换、合并或显式更新所选组。最多 50 组，每组 100 条。普通替换值也会保存，可恢复模式仍生成独立占位符；合并遇到同词不同替换值时拒绝，避免静默覆盖。规则仅在主动保存时以明文写入当前用户应用数据目录的 `local.petdesk.maskdesk/keyword-groups.json`，清空会话不删除已保存组。
- Word / TXT：导入 `.docx` 或 UTF-8 / 带 BOM 的 UTF-16 `.txt`，共用关键词库、格式识别和 AI 还原流程。提取文字后可编辑、预览，导出 UTF-8 TXT 或新的纯文字 DOCX。Word 提取正文、表格及页眉页脚、脚注尾注；表格转文字，不保留排版、图片、批注或删除的修订，不识别图片内文字。旧 `.doc` 请先另存为 `.docx`。
- 敏感格式识别：文本和工作表均可识别中国大陆手机号、常见邮箱及 18 位身份证候选，显示次数与所在列，勾选确认后才加入规则。身份证日期/校验位未通过的号码标为疑似，姓名、公司和项目名请手动补充；识别不保证完整。
- AI 结果还原：默认开启“可恢复关键词替换”，为关键词自动生成唯一 `[[PD_…]]` 占位符，忽略右侧普通替换值。把 AI 返回文本或 Markdown 表格粘贴到“AI 结果还原”，选择对应映射即可还原。要求 AI 保留占位符原样；未知或被改写的占位符不猜测还原。关闭可恢复模式则使用手填替换值，不生成映射。
- 映射保管：每次预览保留独立映射，单会话最多 20 份；改规则或打开新文件不影响旧映射。关闭工具或清空会话会丢失内存映射，跨会话请在还原页用密码加密保存 `.pdmap`，回来后输入密码导入。映射含原值，别与脱敏结果一起发给 AI；忘记密码无法恢复。
- 表格：选择 `.xlsx` 或 UTF-8 `.csv`，选择工作表并勾选需处理的列；每列可设保留首尾、固定值替换或使用文本页关键词规则。预览前 20 行及全表修改数，再导出新的 `.xlsx`。
- 输出文件名默认使用 `原文件名_脱敏_日期时间.扩展名`，Excel 另加工作表名，例如 `客户名单_客户_脱敏_20260929-153012-123.xlsx`；保存对话框中可修改，已有文件不会覆盖。
- 中间固定遮盖为 `****`，空值保持为空。短值长度不够保留首尾时整项遮盖，防止完整暴露。修改输入或规则后须重新预览。
- 导出仅含当前工作表，所有单元格作为文本值写出，未选择的列和保留表头仍有原值。格式、公式、其他工作表、批注、图片和宏不导出；公式使用已有缓存结果，日期转换为 ISO 文本，数字的格式补零不保留，文本前导零保留。请检查预览和导出结果后再分享。
- 全程本地，格式识别仅供审阅。原文、规则和表格不自动写入日志或配置；主动保存规则组会写本机明文库，主动保存映射会写加密文件。关闭工具或清空会话释放临时数据，主动复制的内容仍留在系统剪贴板。源文件只读，不覆盖已有输出文件。星号掩码、固定值替换和普通关键词替换不可恢复。
- 文件上限 20 MiB，XLSX 解压上限 100 MiB，单工作表最多 50,000 行、128 列、200,000 个单元格。首版不支持旧 `.xls`、加密文件、GBK CSV 或保留原样式。

实施边界和后续迭代见 [脱敏工具实施计划](docs/脱敏工具实施计划.md)。运行 `npm.cmd run smoke:maskdesk` 可在隔离会话中验证真实 Tauri 界面的文本替换、列脱敏与导出。

已实现：透明悬浮、有效帧检测、基础动画、拖动位置保存、屏幕范围约束、单实例、托盘、一次性与固定重复会议提醒、历史一键清除、确认和稍后提醒、免打扰、缩放、减少动画、原子保存和损坏备份恢复、离线导入。

支持标准 Codex V1（1536 × 1872）与 V2（1536 × 2288）WebP 精灵图。V2 当前只播放基础九行动作，不实现视线跟随。会检测空白帧，避免动作闪空白。

尚未实现：Codex 真实通知连接、其他应用事件适配、系统鼠标切换、天气、节假日、日历同步、照片生成、支付、自动更新与开机启动。

提醒在主进程中检查，不依赖界面是否打开。软件退出、系统关机期间无法提醒；重新启动或休眠唤醒时会检查未处理的逾期项。提醒是本地尽力交付，Windows 通知可能受系统设置影响，以应用内列表为准。硬件休眠、真实多屏和长时间资源占用仍需要在你的日常环境中验证。

## 本地文件

```text
src/             主进程、受限 IPC 桥接、存储及提醒逻辑
ui/              陪伴空间、透明桌宠、精灵动画
tools/           导入、启动验证、便携打包
test/            本地存储与调度测试
assets/          本项目绘制的程序图标
.local-pets/     仅本地使用的初始宠物资源（Git 忽略）
.data/           个人设置、提醒、导入资源、日志和运行时缓存（Git 忽略）
artifacts/       自动化验证截图与结果（Git 忽略）
```

开发版在当前目录 `.data/` 保存个人数据。便携版在可执行文件所在目录的 `.data/` 保存数据，请放在当前用户可写的目录。移动便携版时一并保留 `.data/`。日志可能含本地文件路径，反馈前请检查。

数据文件为 `.data/state.json`，上一次有效版本保存在 `state.json.bak`。损坏文件保留为 `state.corrupt-时间戳.json`；恢复时会在界面提示，不静默丢弃。

导入不会修改原 ZIP 或原宠物目录。ZIP 支持文件在根目录或同一个子文件夹内，不需要手动解压；单个包上限 25 MB，图片上限 20 MB。导入失败不会切换当前宠物，原有提醒、缩放与位置也会保留。网站接口发生变化时可改用本地 ZIP 导入。

也可以通过界面选择含 `pet.json` 的文件夹，或在开发目录执行（此命令只处理文件夹）：

```powershell
npm.cmd run import-pet -- "C:\Pets\my-pet"
```

界面导入的宠物优先于初始开发资源。图片不上传；通过分享链接导入时仅向 Codex Pets 请求详情与资源，不发送本地图片或账号凭据。支持取消下载。

## 验证

```powershell
npm.cmd test
npm.cmd run smoke
```

`test` 同时运行 JavaScript 工具/界面协议测试和 Rust 后端测试，覆盖提醒、重复会议、旧数据兼容、持久化及损坏恢复。

`smoke` 打开真实 Tauri 窗口，以独立数据和自动生成的测试宠物验证页面就绪、设置保存、提醒到期、换宠、旧版收起状态迁移和窗口恢复。报告在 `artifacts/tauri-smoke-*`。运行 `npm.cmd run smoke -- --launcher` 还会经过双击入口使用的 Windows PowerShell 5.1 启动脚本。测试不会修改日常提醒，也不会发送系统通知。

已有宠物时，启动只加载桌宠窗口；双击宠物或通过右键、托盘打开陪伴空间。玩具窗口在首次使用逗猫棒或放球时才创建，跟随鼠标不会创建玩具窗口。陪伴空间关闭后保留未保存的表单，已使用的窗口因此仍可能占用内存。动画使用单张循环缓冲，切换或取消预览时释放旧缓冲。

可用 `tools/measure-memory.ps1 -Executable <正式版EXE路径> -OutputDirectory <项目artifacts下的新目录>` 对比版本：复制当前宠物到隔离数据目录，启动正式 EXE，关闭本次测试的主面板，等待 12 秒后采样三次，结果写入 `memory.json`，最后退出测试进程。私有提交内存和工作集是不同口径；工作集汇总包含重复计算的共享页面，不能直接当作独占物理内存。该测试不执行工作集整理，也不修改日常提醒。

## 生成便携版

```powershell
npm.cmd run package
```

默认通过 Tauri 构建。产物在 `release/`：包含 `PetDesk.exe` 的便携目录和 ZIP、NSIS 安装包，以及各自的 `.sha256` 校验文件。默认不携带私人宠物和个人数据；首次运行需要导入宠物。便携版所在 Windows 电脑需要 WebView2 Runtime；安装包会在缺失时下载引导程序。当前构建未签名，尚无自动更新服务。详细步骤见 [发布指南](docs/发布指南.md)。

## 扩展方向

保持宠物播放器、提醒存储与外部适配器分离。下一阶段优先验证一个真实 Codex 通知入口，并把事件统一为来源、标题、状态、任务 ID；不依靠读取认证令牌或全屏识别来监听。鼠标主题作为独立模块开发，先验证异常退出后的恢复机制。

## 公开发布前

当前基础客户端代码采用 MIT 许可证（见 `LICENSE`）；后续付费扩展的范围尚未实现。第三方宠物素材的权利归原作者，不适用本项目的 MIT 许可证。不要把 `.local-pets` 或 `.data` 加入公开仓库。源码提交到 Git 仓库，便携 ZIP 上传至 GitHub Releases；两者分开发布。
