# PetDesk：从桌面陪伴到本地工作助手

整理日期：2026-10-01。依据本项目三段开发对话、Git 提交、README 与验证记录整理。反馈以意译呈现；历史尝试、当前能力与后续想法分别说明。

## 可以直接用于分享的开场

最开始，我只是想让一只可爱的宠物住在桌面上：可以互动，能提醒我开会，以后还能连接其他软件的通知。真正自己用起来后，我发现决定它能不能留下来的，是一些很具体的小事：提醒字够不够大、拖到屏幕边缘会不会闪、双击后能不能直接用、后台内存占用是否合理。

所以这个项目的迭代，是从“做出一个可爱的功能”，逐渐变成“把一个每天会用的小工具做稳定”。目前它已经有桌面陪伴、会议和护眼提醒、逗猫棒、放球取回、跟随鼠标，以及一个按需打开的本地脱敏工具。脱敏工具解决的是另一个真实需求：把资料交给 AI 之前替换敏感关键词，分析完成后再在本地还原。

| 交付给别人 | 小白只会双击，是否一定要装 npm | 提供 EXE、便携 ZIP、安装包和快捷方式入口；使用者无需 Node.js 或 Rust |

| 陪伴感 | 想逗宠物、放球让它取回、跟随鼠标；右键也要能操作 | 三种互动及右键入口，支持 Esc 和菜单退出；隐藏、拖动或换宠时结束互动 |
| 资源占用 | Tauri 之后内存仍不小，想看占用并整理 | 窗口按需创建、动画复用单张缓冲、清理旧预览；提供本程序内存查看和工作集整理，不承诺系统加速 |
| 工作工具 | 给 AI 前替换关键词，Excel 按列保留首尾 | 独立进程的本地脱敏工具，通过桌宠入口打开；文本与表格预览后导出新文件 |
| AI 闭环 | 识别常见敏感格式，AI 分析完能映射回来 | 手机、邮箱、身份证候选需确认；唯一占位符和独立映射支持本地还原，映射可加密保存 |
| 复用与文件 | 关键词要组织复用，支持 Word/TXT，导出名称能追溯来源 | 命名关键词组、DOCX/TXT 导入、原文件名加脱敏标记和时间的输出命名 |
| 最新待办 | Word 为什么不能保留图片排版，能否复制一份再修改 | 当前仍是提取文字并导出纯文字 DOCX。保留原排版的副本替换是待实现需求，本次发布不包含 |

## 以后能复用的做法

1. **先跑通一条完整使用路径。** 下载 → 解压 → 双击 → 导入宠物 → 体验提醒 → 托盘退出，比先堆天气、支付和多个软件接入更容易验证产品价值。
2. **把反馈写成可复现的场景。** “不好用”改成“外接屏顶部拖不到”“共享屏幕后通知不能关闭”“展开瞬间图片变大”，才能定位和回归。
3. **愿意撤回不稳定的交互。** 侧边隐藏从想法、试用到取消，说明保留一个简单稳定的状态也可以是有效迭代。
4. **分开衡量安装体积、启动速度和常驻内存。** 换 Tauri 解决了分发包体积问题，窗口数量、动画缓冲和资源生命周期仍需单独优化。
5. **常驻入口和重功能分开。** 桌宠负责陪伴与快捷入口；脱敏工具按需启动独立进程，关闭后退出。这种结构也适用于未来其他本地工具。
6. **预览、确认、输出副本。** 宠物导入先预览；时间解析后检查；敏感格式只给候选；脱敏生成新文件。让用户在关键结果产生前看得见、能纠正。
7. **脱敏和还原是一对能力。** 可恢复替换需要一致的占位符、对应映射、跨会话保管和未知占位符处理；普通星号遮盖无法还原。
8. **规则是可复用资产。** 将关键词按客户、项目或用途分组，而不是每次重新输入；加载、合并和更新的语义必须清楚，冲突不能静默覆盖。
9. **测试不能只看进程还活着。** 还要验证页面就绪、真实按钮、导出内容、托盘恢复和启动器退出；性能比较使用相同宠物、缩放和采样条件。
10. **区分源码与交付物。** 代码放仓库、安装包放 Releases，个人提醒和第三方宠物不混入发布包；下载说明直接面向普通使用者。

## 可以讲的技术结果，以及不能夸大的部分

- 迁移阶段记录的便携包约从 151.01 MiB 降到 2.20 MiB。这是当时 Electron 与 Tauri 的版本对比；最新加入脱敏能力后的包以 Release 附件实际大小为准。Tauri 使用系统 WebView2，不代表所有运行依赖都装进了这个小 ZIP。[迁移记录](Tauri迁移.md)
- 2026-09-28 同机、同宠物场景下，私有提交内存从 368.0 MiB 降到 213.1 MiB，约减少 42%。这不是任务管理器默认内存列，也不是所有机器的承诺。[内存优化记录](内存优化记录.md)
- 脱敏在本地执行，但导出是否满足分享要求仍需审阅：未选择列保留原值，Word 不做图片 OCR，姓名和公司名需补充关键词，格式识别不保证完整。
- 当前定位是 Windows 自用预览版。跨机器启动、多屏、休眠唤醒和长期资源占用需要继续积累真实验证。

## 两个现场演示

**演示一：桌宠陪伴与提醒。** 双击 EXE → 导入宠物 → 拖动到桌面 → 右键跟随鼠标或放球取回 → Esc 结束 → 双击打开陪伴空间 → 点击“体验一次提醒”。可展示不打开主面板也能收到应用内提醒。

**演示二：给 AI 前脱敏，结果回到本地还原。** 打开本地数据脱敏 → 用虚构客户名和项目名建立关键词 → 生成可恢复预览 → 复制带占位符的文字 → 将保留占位符的示例回复粘贴到还原页 → 选择同一份映射还原。再展示关键词组保存，以及 Excel 选列、预览、导出副本。演示无需真的调用外部 AI，映射不随脱敏文本发出。

## 下一阶段优先级

1. Word 副本替换并保留排版图片：先定义正文跨片段替换、表格、页眉页脚、修订和嵌入对象的覆盖边界，再验证复杂文档。
2. 扩大真实 Windows 使用验证：干净机器、Teams 共享、多屏与缩放、休眠恢复、长时间运行。
3. 接通一个真实外部通知来源，验证完整事件流，再考虑其他应用适配。
4. 根据真实使用反馈决定照片生成、鼠标主题、天气日历等扩展，不提前把愿景写成现有功能。

## 适合结尾的一句话

这个项目最有价值的积累，是把自己每天遇到的不方便，变成能够复现、能够验证、能够交付的小改进；可爱的桌宠是入口，稳定、低门槛和本地可控才是它能持续被使用的原因。
