# PetDesk 0.1.0 Preview · 2026-10-01

Windows x64 自用预览版。首次 GitHub Release，包含当前桌宠、提醒与本地脱敏功能。

## 下载与启动

- 便携版 ZIP：约 3.23 MiB，完整解压后双击 `PetDesk.exe`。可以双击 `启动本地脱敏.vbs` 单独打开脱敏工具。
- NSIS 安装包：约 2.60 MiB，适合安装到电脑使用。缺少 WebView2 Runtime 时会下载引导程序；便携版需要系统已有 WebView2。
- 使用者无需 Node.js、npm 或 Rust。不要下载 GitHub 自动附加的 Source code 作为可运行程序。
- 首次使用请导入自己的宠物资源；包内不包含个人数据或第三方宠物。
- 每个包附有 `.sha256`，可用 PowerShell `Get-FileHash <文件路径> -Algorithm SHA256` 核对。

## 当前功能

- 透明悬浮宠物、拖动、尺寸设置、托盘、右键菜单；ZIP、文件夹和分享链接导入。
- 逗猫棒、放球取回、跟随鼠标；单击互动、双击陪伴空间。
- 一次性和固定重复会议提醒、快捷时间输入、确认与推迟、免打扰、已结束记录清理、护眼提醒。
- 独立进程的本地脱敏工具：文本关键词、规则组复用、常见敏感格式候选、Excel/CSV 按列处理、Word/TXT 导入。
- 可恢复占位符、AI 返回文本/Markdown 表格还原、密码加密保存映射；输出副本不覆盖源文件。
- Tauri 2 + Rust；按需创建窗口、动画缓冲复用。

## 已知边界

- 当前未签名、无自动更新。退出、关机期间不能实时提醒；系统通知受 Windows 设置影响。
- Word 导出为纯文字 DOCX，不保留排版图片；Excel 只导出当前工作表的文本值，不保留公式和原样式。识别结果需审阅，未选择列保留原值。
- 普通星号遮盖不可还原。可恢复映射含原值，应留在本机；关闭会话前按需加密保存。
- 照片生成、真实外部通知连接、鼠标主题、天气、日历同步、付费功能仍未实现。
- 干净 Windows 机器、Teams 共享、多屏混合 DPI 与长期运行仍需更多实机验证。

## 升级

先从托盘退出旧版，备份旧便携目录的 `.data/`，再复制到新版 EXE 同目录。不要将自己的 `.data/` 随软件分发。脱敏关键词库在当前用户应用数据目录；加密映射文件由用户自行保存。
