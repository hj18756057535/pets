# PetDesk 0.1.0 Preview · 2026-10-07

Windows x64 自用预览版。本次新增签到、陪伴日历、情绪表达和节日提醒，并改进逗猫棒互动。

## 本次更新

- 签到续火花：每个本机自然日签到一次，连续次日签到累加火花；漏签后重新点亮，累计签到保留。
- 陪伴日历：在会议提醒页切换月份、查看节日和事项，选中日期后可直接填写该日的提醒。
- 情绪表达：默认每 20 分钟说一句随时段和签到状态变化的心情；偏好设置可关闭或调整为 1～180 分钟。
- 节日提醒：元旦、情人节、妇女节、劳动节、儿童节、国庆节和圣诞节当天 09:00 后提醒一次，晚启动可补发。暂不含农历节日、法定放假调休和外部日历同步。
- 逗猫棒：新增蓄势、扑抓、挥手庆祝和休息阶段，显示星光与本轮抓取次数；减少动画设置会关闭羽毛摆动和星光动画。
- 新增暂停隔离测试进程后恢复的验证流程，检查逾期提醒补发、重复会议安排与护眼提示重置。

## 下载与启动

- 下载本次 Release 的便携版 ZIP，完整解压后双击 `PetDesk.exe`；也可下载 NSIS 安装包。
- 可双击便携包内的 `启动本地脱敏.vbs` 单独打开脱敏工具。
- 使用者无需 Node.js、npm 或 Rust。不要将 GitHub 自动附加的 Source code 当作可运行程序。
- Windows 需要 WebView2 Runtime；安装包会在缺失时下载引导程序，便携版需系统已有 WebView2。
- 首次使用请导入自己的宠物资源，发布包不含个人数据和第三方宠物素材。
- 两种下载均附有 `.sha256` 文件，可用 PowerShell `Get-FileHash <文件路径> -Algorithm SHA256` 核对。

## 升级

先从托盘退出旧版，备份旧便携目录的 `.data/`，再将其复制到新版 EXE 同目录。请使用新的解压目录，不要直接覆盖正在运行的旧版。脱敏关键词库仍保存在当前用户应用数据目录；加密映射文件由用户自行保存。

## 已知边界

- 当前未签名，尚无自动更新；本次继续沿用 `0.1.0` 应用版本，以日期区分预览发布。
- 软件退出、关机期间不能实时提醒，系统通知受 Windows 设置影响。
- Word 导出为纯文字 DOCX，不保留排版和图片；Excel 只导出当前工作表的文本值，不保留公式及原样式。敏感格式识别结果需审阅，未选择列仍保留原值。
- 普通星号遮盖不可还原。可恢复映射含原值，应留在本机；关闭会话前按需加密保存。
- 干净 Windows 机器、Teams 共享、多屏混合 DPI 和长期运行仍需更多实机验证。
