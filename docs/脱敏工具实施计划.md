# 本地脱敏工具 · 首版实施计划

## 产品与架构

在现有 Rust + Tauri 安装包中增加 `PetDesk.exe --maskdesk` 独立运行模式。桌宠、托盘和陪伴空间只负责启动入口，表格解析与脱敏运行在另一个进程；关闭工具即退出该进程，不启动桌宠、提醒计时器或托盘。暂不引入模型、云服务或 DataFog 等识别引擎。

## 首版交付

- 文本：多条字面关键词替换，大小写敏感、长词优先、单遍替换（替换结果不会被后续规则再次替换），命中统计、预览与复制。
- 表格：导入 `.xlsx` 或 UTF-8 `.csv`，选择工作表，逐列设置保留首尾、固定值替换或关键词替换；预览前 20 行与全表修改数量，导出一个新的 `.xlsx`。
- 保留首尾按 Unicode 字符计算，中间固定为 `****`；短内容无法同时保留指定首尾时整项变成 `****`，空值保持为空。
- 导出仅包含当前工作表，所有单元格写为文本值；不保留其他工作表、格式、公式、批注、图片或宏。公式仅读取文件内缓存值，不计算公式。日期转 ISO 文本；数字显示格式（含格式补零）不保留，文本前导零保留。
- 未选择列和启用保留的表头仍保留原值，导出前在页面明确说明；格式识别只提供候选，不宣称识别完整或完全匿名化。
- 数据与规则不自动写入配置、日志和历史；清空会话或关闭窗口释放临时引用。主动保存规则组会生成本机明文规则库，主动保存映射会生成加密文件；主动复制会写系统剪贴板。
- 源文件只读；输出必须是不存在的新文件，不覆盖源文件或已有文件。预览与导出使用同一份内存快照，修改规则必须重新预览。

## 边界与验证

首版限制：单文件 20 MiB、XLSX 解压总量 100 MiB；每个工作表最多 50,000 行、128 列、200,000 个矩形单元格，文本总量最多 32 MiB。UTF-8 CSV 支持 BOM、引号和换行，不猜测 GBK 编码。

单元测试覆盖重叠关键词、不级联替换、中文与短值、空值、CSV 编码/引号/前导零、工作表隔离、公式文本化、输入限制与禁止覆盖。原有测试与真实 Tauri 冒烟验证确认桌宠功能及新窗口流程。

2026-09-29 首版验证完成：36 项 JavaScript 测试、10 项 Rust 测试通过；原有桌宠冒烟测试通过；脱敏工具真实 Tauri 冒烟测试 10 项检查通过（包括读取最终输出 XLSX，确认不存在测试原值、公式和额外工作表）。测试使用合成数据与隔离目录。完整 NSIS/便携包尚未重新构建；本次已更新便携打包脚本，包含独立启动入口。

## 第二阶段：格式识别与 AI 结果还原

已实现的流程：粘贴文本或导入表格 → 识别候选 → 人工勾选确认 → 加入关键词 → 可恢复预览 → 将脱敏结果交给 AI → 粘贴 AI 回复 → 选择原映射 → 还原预览并复制。表格识别覆盖当前工作表全体数据行，是否跳过表头由选项决定；确认候选后将所在列设置为关键词替换。

- 识别中国大陆手机号（连续数字、空格/短横线分组、可带 +86）、常见 ASCII 邮箱、18 位身份证格式。身份证检查日期与校验位，未通过的号码仍作为“疑似身份证”供审阅；不验证号码归属、实际分配、完整行政区划或真实身份。
- 同值候选合并并显示出现次数、所在列，最多展示 100 种，超出会提示分批处理。姓名、公司名、项目名仍需手工补关键词。识别结果不会直接改写内容，加入关键词后按字面匹配全部相同内容。
- 默认开启“可恢复关键词替换”：忽略普通模式的手填替换值，生成 `[[PD_映射编号_序号]]` 唯一占位符。相同原值在同一次文本/表格预览中保持一致，长词优先，不级联。只有实际命中的原值进入映射。
- 每次预览生成独立映射，切换文件、改规则或新预览不会覆盖旧映射；单次会话保留最多 20 份，达到上限时要求先保存再清空，不静默丢弃。每份最多 1000 个原值。映射选择器展示来源、时间、条数和编号。
- AI 回复支持纯文本或粘贴的 Markdown 表格。仅还原对应映射中的完整占位符；未知或仍带 `[[PD_` 前缀的残缺占位符保留并计数。不猜测被改写、删除或翻译的称呼，也不能发现所有被删掉的占位符。提供可复制给 AI 的占位符保留说明。
- 星号掩码、固定值替换、普通关键词替换不保存逆映射，不能事后反推。原文已含 PD 占位符时拒绝再次进行可恢复处理，避免嵌套映射。
- 跨会话：在还原页用至少 10 字符密码保存 `.pdmap`，之后输入密码导入。映射包含原值，不应与脱敏数据一起发送。密码丢失无法恢复；关闭前应主动保存。清空会话前会提示映射丢失。

加密文件 V1：8 字节版本头 `PDMAP001`、16 字节随机盐、12 字节随机 nonce、AES-256-GCM 密文与认证标签。用 PBKDF2-HMAC-SHA256 / 600,000 次从密码派生密钥，头部作为认证附加数据；每次保存使用系统随机数生成新盐和 nonce，不存储密码或明文中间文件。文件上限 5 MiB，解析后校验映射编号、占位符、去重与原文大小，密码错误、文件篡改及映射冲突均拒绝导入。只创建新文件，不覆盖已有文件。临时密钥与序列化明文缓冲使用 `Zeroizing`；不承诺清除系统剪贴板、交换文件或所有进程内存副本。

实现使用 [ring AEAD](https://docs.rs/ring/0.17.14/ring/aead/struct.LessSafeKey.html) 和 [PBKDF2](https://docs.rs/ring/0.17.14/ring/pbkdf2/index.html)，成本参数参考 [OWASP PBKDF2 说明](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html#pbkdf2)。身份证日期和校验规则参考 [GB 11643-1999 公民身份号码](https://zjw.beijing.gov.cn/Portals/0/zhuanti/fazhan/%E8%BA%AB%E4%BB%BD%E8%AF%81GB11643-1999.pdf)。

第二阶段验证：`npm.cmd test` 的 36 项 JavaScript 与 18 项 Rust 测试通过；`npm.cmd run smoke:maskdesk` 的 23 项真实窗口及文件内容检查通过，涵盖确认候选、文本与表格可恢复替换、旧映射保留、未知占位符提示、加密导出与清空后重新导入还原。测试仅使用合成数据，没有向外部 AI 发送任何内容。正式安装包尚未重新构建。

### 引擎选型复核（2026-09-29）

| 方案 | 已核实能力与许可证 | 中文与资源结论 | 当前选择 |
| --- | --- | --- | --- |
| 本项目本地规则 | Rust 正则、日期与校验位校验，复用已存在依赖，不引入模型 | 有可复现中文上下文与负例测试；不是中文姓名/公司名 NER，也不是完整准确率基准 | 用于本次三类结构化格式识别 |
| DataFog Core | Rust；MIT；公开列出 EMAIL、PHONE、SSN 等类型；支持 mask、pseudonymize、tokenize，tokenize 需要应用提供映射服务 | README 未给出中国大陆身份证检测器或中文准确率证据。项目声称无需模型/词典下载；Windows 私有提交与本项目对比未实测，不能引用其宣传当作内存结论 | 保留候选，不作为本次必需依赖 |
| Presidio | MIT；可扩展正则、校验器和 NER；提供 Python 等运行方式 | 是否支持目标中文场景取决于选用的识别器/模型；中文质量和资源占用尚未在本机实测。推断引入完整运行环境会增加打包复杂度 | 需要姓名/地址等语义识别时再评估 |

来源：[DataFog 官方仓库](https://github.com/DataFog/datafog-core)、[Presidio 官方仓库](https://github.com/data-privacy-stack/presidio)。本次没有把 DataFog 的 HMAC 假名化当成可逆加密，也没有把第三方“轻量”描述当成本机测量。后续采用候选引擎前，应使用相同合成中文语料分别测量精确率、召回率、冷启动与扫描耗时、私有提交峰值，并记录具体版本与许可证依赖清单。

## 后续迭代

### 已补充：关键词复用与文档文件

- 关键词按命名规则组组织：新建保存、加载替换当前规则、合并、显式更新所选组。最多 50 组，每组最多 100 条；同名新建拒绝，合并同词异值拒绝，切换模式不丢普通替换值。清空会话保留规则库。
- 规则库位于当前用户应用数据目录 `local.petdesk.maskdesk/keyword-groups.json`，仅用户主动保存时写入。文件含明文关键词及普通替换值，界面明确说明；不混入原文或恢复映射。临时文件写完并同步后原子替换，损坏的原库不静默重置。测试使用隔离目录。
- Word 支持 `.docx`；提取正文、表格文字、页眉页脚及脚注尾注，文字跨 run 仍可连续匹配。删除的修订与批注不提取。图片没有 OCR，格式和复杂对象不保真，嵌入正文 altChunk 拒绝并提示转换。提取后必须审阅；附加部分汇总在正文后，不重现分页位置。
- TXT 支持 UTF-8（可带 BOM）、带 BOM 的 UTF-16LE/BE；无效编码明确报错，不猜测 GBK。文件上限 20 MiB，提取后文字 2 MiB，DOCX 解压总量 100 MiB，单 XML 16 MiB。
- 预览可导出 TXT（UTF-8）或 DOCX（重新生成纯文字文档），不复制原 ZIP 的媒体、批注、修订记录、关系或元数据。源文件不修改；导出使用预览快照，修改内容/规则后禁用旧导出。Word/TXT 复用原有格式识别和可恢复映射。
- 默认文件名使用原文件名、脱敏标记及毫秒时间戳；Excel 另加工作表名，过滤文件名非法字符并限制长度。用户可以在保存对话框修改；同名文件仍拒绝覆盖。

本轮验证：36 项 JavaScript、21 项 Rust 测试通过；真实 Tauri 冒烟 33 项检查通过，包括规则保存/更新/清空后复用、Word/TXT 导入与导出、文件名、文档可恢复映射，以及直接读取输出 DOCX/TXT 确认无已替换原值。页面截图检查通过。测试程序输出到独立目录，避免占用正在运行的开发版桌宠；未关闭用户窗口，未重建正式安装包。
