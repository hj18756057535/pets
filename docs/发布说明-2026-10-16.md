# PetDesk 0.1.0 Preview · 2026-10-16

Windows x64 自用预览版。本次新增最多三只宠物同时陪伴，并优化隐藏窗口的内存使用。

## 本次更新

- 在陪伴空间的“桌面小伙伴”添加最多两只伙伴，与主宠同时显示；每只独立拖动、保存位置，伙伴可分别替换或移出。
- 三只共用缩放、减少动画和显示/隐藏设置。主宠负责提醒气泡和玩具互动，另外两只支持单击挥手、双击或右键打开陪伴空间。
- 共用主进程、后台检查循环和 WebView2 浏览器环境，后端复用相同精灵图的压缩数据；移出伙伴时销毁窗口并释放引用，保留本地导入素材。
- 隐藏或最小化窗口时请求 WebView2 低内存模式，恢复显示时恢复正常模式；隐藏动画暂停，停止互动后缩小玩具绘制区域，陪伴空间保留未保存表单。
- 内存页分别显示进程数、工作集合计和私有提交，便于观察占用变化。

## 下载与升级

- 下载本次 Release 的便携 ZIP，完整解压后双击 `PetDesk.exe`；也可选择 NSIS 安装包。无需 Node.js、npm 或 Rust。
- Windows 需要 WebView2 Runtime；安装包会在缺失时下载引导程序，便携版需系统已有 WebView2。
- 先从托盘退出旧版，备份旧目录的 `.data/`，再复制到新解压目录中 EXE 所在位置。不要覆盖正在运行的旧版。
- 发布包不含个人数据或第三方宠物素材；首次使用请自行导入。不要下载 GitHub 自动附加的 Source code 作为可运行程序。
- ZIP 和安装包均附 `.sha256` 校验文件，可用 PowerShell `Get-FileHash <文件路径> -Algorithm SHA256` 核对。

## 已知边界

- 三只仍各自需要图片解码和渲染内存，不能保证总占用维持在约 200 MB。工作集合计含共享页面重复计算，私有提交也不等于物理内存。
- 当前未签名，尚无自动更新；继续沿用 `0.1.0` 应用版本，以日期区分预览发布。
- 软件退出、关机期间不能实时提醒，系统通知受 Windows 设置影响。
- 干净 Windows 机器、Teams 共享、多屏混合 DPI 和长期运行仍需更多实机验证。

- 39 项 JavaScript 测试、27 项 Rust 测试通过。

- 两个额外窗口均完成画布绘制检查。
- Tauri 正式构建、便携 ZIP 与 NSIS 安装包生成成功；便携 EXE 与编译产物一致，包内容和 SHA-256 校验文件核对通过。
