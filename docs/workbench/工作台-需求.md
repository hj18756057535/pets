## 范围与规则

- 在现有 PetDesk 主面板提供每日待办和知识快捷入口，沿用已确认 Demo 的布局，不包含收件箱、跟进或知识正文管理。
- 待办支持快速新增、编辑、按日期查看、完成与重新打开、移除与撤销；可记录时间、分类、重要程度及备注。时间用于安排展示，不自动创建会议提醒。
- 日期和时间使用通用选择器，中文、24 小时制，配色与 PetDesk 一致；用户确认没有指定组件来源。
- 分类可选择已有值或直接输入新值；保存待办时将新分类加入可复用列表，去首尾空白并合并仅英文大小写不同的名称。
- 待办按计划日期所在月份归档；跨月改期保留事项 ID、完成状态及备注，不丢失、不重复。分类和知识入口独立保存。
- 知识入口支持添加、编辑、搜索、固定、移除。Obsidian 打开笔记或搜索，网页交给浏览器，本机资料交给默认应用或资源管理器。移除入口不操作原文件。
- 正式待办从空数据开始，不导入 Demo、旧浏览器存储或其他项目业务内容。保存失败保留表单，加载失败显示错误并允许重试，不能以空数据覆盖损坏记录。

## 验收条件

1. 保存并重新打开后，待办、自定义分类及知识入口保留。
2. 同月操作只更新对应月份；跨月改期后原月份不显示、目标月份恰好一条，未完成的跨月写入可以恢复。
3. 损坏 JSON 保留原件并尝试有效备份恢复；无有效备份时明确报错。
4. Obsidian 中文路径及特殊字符正确编码；拒绝创建、追加、覆盖笔记或执行脚本的链接。
5. 现有陪伴、会议、脱敏及多宠行为保持；代码测试、编译和真实窗口、人工使用分别记录。
