## 页面与复用

在现有主面板增加“每日待办”和“知识快捷入口”，复用已确认 Demo 的浅绿、米白、任务行、常用入口卡片与编辑弹窗；保留原来的陪伴、会议、偏好及脱敏入口。主面板和桌宠仍共用原进程，脱敏仍独立按需启动。

- 待办：快速输入、日期切换、状态筛选、编辑、完成/重新打开、移除与撤销。分类输入框带已有选项，也能直接输入新名称。
- 时间：使用固定版本 Flatpickr 4.6.13，中文与 24 小时制，统一非原生弹层和 PetDesk 主题；共享实现为 `ui/date-time-picker.mjs` 与 `ui/date-time-picker.css`。
- 知识：入口名称、位置、说明和固定状态可维护，支持搜索。可选择 Markdown、资料文件或文件夹，也可粘贴 Obsidian URL / 网页链接。
- 加载及保存失败显示错误，表单保留；加载失败不能当空列表覆盖。编辑弹窗未关闭时，外部返回首页请求不打断输入。关闭面板仍沿用原有隐藏窗口、保留页面的行为。
- 日期使用本机自然日，与现有桌宠一致；可见时定期检查跨天，休眠恢复后也检查。隐藏期间不刷新工作台数据。
- 工作台使用独立前端 ID、事件属性和 IPC，不参与宠物动画状态广播。

选择器依据 [Flatpickr 配置](https://flatpickr.js.org/options/)和[本地化文档](https://flatpickr.js.org/localization/)接入；MIT 许可证随 vendor 资源打入应用。运行时资源来自本地，不使用 CDN。

## 按月存储

沿用应用已有数据目录选择规则，开发模式位于仓库 `.data/`，便携或安装模式沿用原实现；会议和宠物的旧 `state.json` 不变。

```text
<应用数据目录>/workbench/
  settings.json             分类与知识入口
  settings.json.bak         最近有效配置备份
  tasks/
    2026-10.json             计划日期属于 2026-10 的待办
    2026-10.json.bak         最近有效月文件备份
    2026-11.json
  pending-move.json          仅跨月迁移未完成时存在
```

文件版本为 1，字段与校验以 Rust 类型为准。读取待办只访问所选月份，必要时另读当前月份生成今日摘要，不遍历全部历史。知识页独立读取配置，即使待办月文件或迁移记录损坏也不阻塞知识入口管理。

分类去除首尾空白，以不区分英文大小写的名称复用；新名称随保存登记。待办以 UUID 标识，完成时间由后端记录。移除采用逻辑标记以支持撤销，月文件保留该记录。

保存先校验、保留有效旧备份，再写临时文件、同步并原子替换。读取发现损坏时保留原件，只从有效备份恢复；无有效备份则报错，不生成空文件覆盖。

跨月改期先持久化迁移意图，再幂等写入目标月、移出原月；两个完成状态备份同步后清理意图文件。下一次待办操作恢复未完成迁移，恢复旧备份不会使已迁移事项回到原月份。操作复用现有后端串行访问，不新增锁、数据库或后台服务。

## 本机打开与权限

工作台通道仅允许 `panel` 窗口调用，主宠、伙伴、玩具和脱敏窗口不获此权限。前端提交入口标识，由后端读取已保存目标并校验，复用 Rust opener；不开放通用 shell 命令或任意程序参数。

- Obsidian 只接受 `open` / `search`，拒绝创建、追加和覆盖参数；本机 Markdown 路径经过编码生成 `open?path=`，参照 [Obsidian URI](https://obsidian.md/help/uri)。
- 网页只接受 HTTP(S)，不接受携带用户名密码的地址。
- 本机路径必须为完整位置；打开前检查存在性，支持资料文档、图片与目录，拒绝程序和脚本作为默认打开目标。
- 不读取、复制或回写知识正文；移除入口不操作原资料。
